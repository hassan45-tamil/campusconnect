Online Campus Club & Activity Portal

Project Description

Online Campus Club & Activity Portal is a web-based platform designed to help students explore college clubs, discover campus events and participate in various activities.

Problem Statement

Students often find it difficult to get information about different college clubs and upcoming activities in one place. This project provides a single platform to access all campus activities.

Project Objectives

- To provide information about college clubs.
- To display upcoming campus events.
- To help students register for events.
- To make campus activities easy to access.

Features

- Modern and responsive user interface.
- Explore different college clubs.
- View upcoming events.
- Search and filter events.
- Register and cancel event registrations.
- Student activity dashboard.

Technologies Used

- HTML – Website Structure
- CSS – Website Design and Styling
- JavaScript – Website Functionality

Project Files

- index.html
- style.css
- script.js
- README.md

How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Explore the Campus Club & Activity Portal.
